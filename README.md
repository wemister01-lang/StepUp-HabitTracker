StepUp — Habit Tracker

StepUp — персональний трекер звичок, створений як навчальний проєкт для ЛНТУ.

Програма допомагає користувачеві створювати звички, відстежувати їх виконання та переглядати статистику.

Можливості:

Додавання нових звичок.
Перегляд списку звичок.
Позначення звичок як виконаних.
Редагування та видалення звичок.
Пошук і фільтрація звичок.
Перегляд статистики виконання.


Використані технології

Python
ООП (об'єктноорієнтоване програмування)
JSON
unittest (автоматизоване тестування)

Запуск проєкту
Склонуйте репозиторій:

git clone https://github.com/wemister01-lang/StepUp-HabitTracker.git

Перейдіть до папки проєкту:

cd StepUp-HabitTracker

Запустіть програму:

python main.py
